# Attribution and distribution status

This project contains the independent AFNO implementation, Burgers/KS solvers, training extension, and experiment assets developed for the included examples. The method reference is **Autoregression-Free Neural Operators for Time-Dependent PDEs**, [arXiv:2605.25413v3](https://arxiv.org/abs/2605.25413v3).

This is not an official release by the paper's authors. The increasing-horizon and balanced training stages are additional experiments. No third-party model repository or paper PDF is bundled. Dependencies retain their respective licenses.
