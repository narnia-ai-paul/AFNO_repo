Ground truth, FNO and AFNO predictions, and absolute errors for 100-step forecasts of Burgers (top; dt=0.01, periodic domain [0,2pi)) and Kuramoto–Sivashinsky (bottom; dt=0.1, periodic domain [0,64)). The main comparison uses validation trajectory 0 for each PDE, fixed by index before KS field export. Both models receive the same initial condition and are compared with identical reference fields. Evolution is performed at 256 spatial points, with decoded readouts Fourier-resampled to the 1024-point reference grid. Each PDE uses a shared, symmetric linear color scale for ground truth and both predictions, and a shared zero-to-maximum linear color scale for both absolute-error maps. Scales cover the complete displayed range without clipping and may differ between PDEs and supplementary examples. The periodic endpoint is repeated only for display, preserving the original grid-center coordinates. The accompanying error curves average MSE over all 100 validation trajectories at each step; full-100 MSE denotes the average over all steps, not just step 100. FNO and AFNO are the labels used throughout these figures. AFNO denotes the completed balanced-curriculum checkpoint: 500 original epochs, 60 warmup epochs, and 40 repair epochs; FNO uses its original 500-epoch checkpoint. Thus training compute is unequal. Results use one initialization seed and the validation set used during method development/checkpoint selection. Independent confirmation is outstanding. No training or canonical-test inference was performed for these figures.
